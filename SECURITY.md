# Security

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue for security problems.

Only the latest code on `main` is supported. There are no versioned releases yet.

## Security model

CrateBridge is a static, client-only web app.

- **No backend, accounts, or secrets.** The repository contains no API keys or credentials, and none are needed to run it.
- **No payments.** Purchases happen on the retailer's own site or app. CrateBridge never sees payment details.
- **Local data only.** Imported tracks, selections, statuses, and settings are stored in the browser's `localStorage`. Nothing is sent to a CrateBridge server, because there isn't one.
- **Outbound traffic:**
  - catalog searches to `https://itunes.apple.com/search`
  - album artwork from Apple's `mzstatic.com` image hosts
  - pages the user chooses to open: Apple, Amazon, Beatport, and Bandcamp listings and searches

### Untrusted input

The following data is untrusted and must be handled safely:

- Pasted tracklists and uploaded CSV files
- iTunes Search API responses, including titles, artist names, and URLs
- Data read back from `localStorage`, which may be stale, malformed, or edited by hand

### Invariants

Changes must keep these properties:

1. **No HTML injection.** Render text through React only. No `dangerouslySetInnerHTML`, `innerHTML`, `eval`, or dynamically built scripts other than the JSONP loader.
2. **JSONP only to Apple.** The JSONP fallback (`loadJsonp` in `src/lib/providers/itunes.ts`) is only called with URLs built by `buildSearchUrl` for `https://itunes.apple.com/search`, and the callback name is generated by the app. Never pass user input or API data as a script URL.
3. **Allowlisted links.** Store and artwork URLs from the API or from storage pass through `safeAppleUrl` / `itunesStoreUrl`, which accept only http(s) URLs on Apple hosts and upgrade them to https. External search links are built from fixed templates with URL-encoded terms. A `javascript:` or other non-https URL must never reach an `href` or `src`.
4. **Safe new tabs.** Links that open in a new tab use `rel="noopener noreferrer"`.
5. **Validated storage.** `src/state/storage.ts` validates every stored field and discards anything invalid. Unreadable data is backed up and replaced with an empty workspace, never executed or trusted.
6. **CSV export escaping.** Exported cells that start with `=`, `+`, `-`, `@`, a tab, or a carriage return are prefixed so spreadsheets don't run them as formulas.
7. **Bounded imports.** CSV uploads are limited to 5 MB.
8. **No new dependencies or third-party hosts** without review. Keep the dependency set small, and commit `package-lock.json`.

### Out of scope

- Vulnerabilities in Apple's, Amazon's, Beatport's, or Bandcamp's services
- Behavior of browser extensions or of a compromised local machine
- Loss of data the user stored in their own browser (it isn't backed up, as the README says)
